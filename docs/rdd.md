# 基本要件
## 対応プラットフォーム
- Android
- iOS

## 機能
- 畳み込みニューラルネットワーク（CNN）の学習
- 推論（学習済みモデルを使った予測）
- モデルの保存とロード（JSON形式）

## 設計方針
- 軽量化とシンプルさを重視
- Kotlinを使い、共通コードでCNNのアルゴリズムを実装
- プラットフォームごとの最適化は必要最低限に抑える
- メモリ使用量と計算効率に注意

# 技術要件
## データ構造
- CNNレイヤー（畳み込み層、プーリング層、全結合層）の定義
- 重みやバイアスを保持するためのデータ構造
- JSONフォーマットで保存・復元可能な設計

## 基本的な操作
- テンソルの操作（加算、乗算、畳み込みなど）をKotlinで実装
-  勾配降下法（SGD）の実装による学習アルゴリズム

## I/O
- 学習データを取り込むインターフェース
- JSONファイルへのモデルのエクスポートとインポート

# 実装予定の主なクラスとインターフェース
## Tensor
- 多次元配列を表現
- 行列演算や畳み込み演算の実装

## Layer
- 畳み込み層、プーリング層、活性化関数、全結合層をサポート
- 各層ごとに前向き（forward）および後向き（backward）操作を定義

## Model
  - 層を構成するシーケンス
  - 学習と推論のロジック

## Optimizer
- SGDやAdamなどの最適化アルゴリズムの実装

## JsonHandler
- モデルのシリアライズとデシリアライズ

# 最小限の機能でのMVP（Minimum Viable Product）
- CNNの基本構造
  - 入力層、1つの畳み込み層、1つの全結合層で構成されるシンプルなモデル
- MNISTのようなデータセットを使用した動作確認
  - 学習が可能であること
  - 学習したモデルで推論ができること
- モデル保存と復元の確認
  - JSONファイルにモデルを保存し、再ロード後に推論可能であること
